# 🛒 E-commerce 电商全栈管理系统 (full-stack-project)

一个基于 **React 前端框架** 与 **Spring Boot 后端架构** 打造的现代电商全栈项目。本项目实现了完整的前后端分离，不仅涵盖了商品浏览、购物车、订单处理及后台管理等核心电商业务场景，更针对高并发环境下的**资损控制、并发超卖、分布式幂等性防重**等核心痛点进行了商业级的架构设计与敏捷重构。

---

## 🛠️ 技术栈架构

项目采用主流的前后端分离架构搭建，保证了系统的高性能与可扩展性：

| 模块 | 核心技术 | 说明 |
| :--- | :--- | :--- |
| **前端 (ecom-frontend)** | React / Vite / Hooks / Redux / Axios / Router | 响应式界面，极致的用户交互与跨组件状态管理体验。 |
| **后端 (sb-ecom)** | Spring Boot 3.x / Spring Security / JWT / Spring Data JPA / Stripe SDK | 健壮的企业级架构，支持声明式事务控制与大模型 Agent 级联重构。 |
| **数据库** | MySQL 8.0 | 稳定的持久化数据存储，基于**行级锁与唯一约束索引**的高并发数据优化。 |

---

## ✨ 核心功能与高并发技术亮点

### 🛍️ 用户前台商城
* **商品智能检索**：支持分类筛选、关键词搜索、URL 状态同步，显著优化分页、复杂筛选下的交互体验。
* **灵活购物车**：实现商品添加、数量动态调整、金额实时计算等复杂的跨组件全局状态管理。
* **安全结算与订单**：前后端统一校验，模拟完整的下单、创建订单流水。

### 🚀 高并发与安全重构（核心亮点）
* **悲观锁/行级锁高性能防超卖**：针对高并发抢购场景，拒绝使用“先查后改”的落后逻辑。利用 **MySQL 行级排他锁**，将库存校验与扣减下沉至数据库单行原子操作（`WHERE quantity >= :buyQty`），配合 **Spring 声明式事务（`@Transactional`）** 确保高并发下库存绝对不超卖。
* **商用级 Stripe 支付 Webhook 闭环与强幂等设计**：全面接入 **Stripe 国际支付网关 Webhook 异步回调**。针对分布式网络丢包与第三方重复回调风险，构建了 **MySQL 唯一约束索引 + 业务状态机前置拦截** 的双重幂等机制，彻底杜绝业务层重复消费。
* **LocalDateTime 精度 30 分钟精准超时关单与库存补回**：全盘重构系统时间体系至 `LocalDateTime`。利用 **Spring Task (`@Scheduled`)** 构建了轻量级定时任务调度器，每隔一分钟扫描超时 30 分钟未支付的延迟订单，执行自动关单并将占坑库存**原子化回滚加回 MySQL**，保障数据最终一致性。
* **AI 协同工程化交付**：在架构升级迭代中，熟练运用 **Cursor 智能体（Agent 模式）** 进行多文件自动化扫描与代码级级联重构，独立定位并解决了由动态变量配置引起的 Spring 依赖注入异常（`Unsatisfied dependency`），高效提升了版本交付效率。

### ⚙️ 后台管理系统
* **商品上架管理**：支持商品信息的增删改查（CRUD）与图片管理。
* **数据看板**：基于 Spring Security + JWT 的多维度基于角色访问控制（RBAC 模型），精细化管理客户、卖家及管理员的权限边界，并对订单状态、库存预警进行直观统计。

## 🚀 本地快速启动指南

### 1. 后端启动 (sb-ecom)
1. 导入项目根目录下的 `database.sql` 到你的 MySQL 数据库。
2. 用 IntelliJ IDEA 打开 `sb-ecom` 文件夹。
3. 修改 `application.properties`（或 `application.yml`）中的数据库账号密码。
4. 运行 `SbEcomApplication.java` 启动后端（默认端口 8080）。

### 2. 前端启动 (ecom-frontend)
1. 用 VS Code 打开 `ecom-frontend` 文件夹。
2. 在终端运行 `npm install` 安装依赖包。
3. 运行 `npm run dev` 启动前端开发服务器。
4. 浏览器访问 `http://localhost:5173` 即可查看效果。
